# direction-approved.md（huashu-design 三方向门 gate 文件）

- 日期：2026-11-01
- 项目：OpenSweep web UI（前端重构）

## 展示的三方向
- A 账本（暖纸×墨×朱砂印）— `方向A-账本.html`
- B 阅片（深底单点缀·青色）— `方向B-阅片.html`
- C 公报（细线报纸）— `方向C-公报.html`

均已在用户浏览器打开；评分报告随本轮回复交付。

## 用户选择原话
> "复查上一步操作和结果，确认无误且无遗漏后，如果还是推荐三方向，那你按照你推荐的来吧。"

即：用户授权由助手（艺术总监角色）代选。

## 助手的选定与理由
**选定：A「账本」。**
理由：OpenSweep 的灵魂差异点是 journal/undo（每一笔操作可逆）——账本母题直接从该内容长出，
概念层不可替换（critique-guide 概念维 9 分路径）；暖纸×朱砂也天然避开 AI 默认审美
（深底霓虹 / 紫渐变 / 暖奶油衬线三件套均未使用）。B/C 的方向卡保留，可作后续换肤储备。

## 按技能降级条款的说明
弱 runtime 下允许"1 完整主版 + 2 轻量变体"：三份初稿均为同规格完整 HTML，未降级。
