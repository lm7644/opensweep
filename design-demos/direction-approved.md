# direction-approved.md（huashu-design 三方向门 gate 文件）

- 日期：2026-11-01
- 项目：OpenSweep web UI（前端重构）

## 展示的三方向
- A 账本（暖纸×墨×朱砂印）— `方向A-账本.html`
- B 阅片（深底单点缀·青色）— `方向B-阅片.html`
- C 公报（细线报纸）— `方向C-公报.html`

均已在用户浏览器打开；评分报告随本轮回复交付。

## 用户选择原话
> "复查上一步操作和结果，确认无误且无遗漏后，如果还是推荐三方向，那你按照你推荐的来吧。"

即：用户授权由助手（艺术总监角色）代选。

## 助手的选定与理由
**选定：A「账本」。**（⚠️ 已于 2026-11-09 被下方「方向变更」取代，仅作历史记录）
理由：OpenSweep 的灵魂差异点是 journal/undo（每一笔操作可逆）——账本母题直接从该内容长出，
概念层不可替换（critique-guide 概念维 9 分路径）；暖纸×朱砂也天然避开 AI 默认审美
（深底霓虹 / 紫渐变 / 暖奶油衬线三件套均未使用）。B/C 的方向卡保留，可作后续换肤储备。

## 按技能降级条款的说明
弱 runtime 下允许"1 完整主版 + 2 轻量变体"：三份初稿均为同规格完整 HTML，未降级。

## 2026-11-09 方向变更（最终上线版，取代方向 A）

### 用户选择原话
> "那这个前端能换成像是前端的模样吗，现在看起来更像是网页而不是应用前端"
> （AskUserQuestion 选定）"深色·对齐桌面 GUI"

即：把「账本」网页风改为**桌面应用式前端**，并与既有 tkinter 桌面 GUI（`gui.py`）的深色设计令牌对齐。

### 最终方向：深色应用骨架
- 结构：固定视口的应用外壳——标题栏（品牌＋引擎/权限/零外联状态 chip）＋图标侧栏（9 视图切换、懒加载、徽标）＋每视图工具条＋底部状态栏；不再是纵向滚动的网页。
- 配色：取自 `gui.py` 令牌——底 `#14161a`、轨 `#101216`、面板 `#1d2026`、主色 `#4f8cff`、副色 `#38d6c4`、语义 ok/warn/bad `#3ecf8e`/`#f0b429`/`#ff5d5d`；主按钮深字亮蓝渐变、危险按钮白字朱红，对比度均 ≥4.5:1。
- 保留全部功能契约：扫描→风险分组→筛选/搜索→勾选→`<dialog>` 确认（高风险需勾选 ack、默认焦点在取消）→清理→Toast→结果三联→撤销/加固/清空撤销区。
- 在线演示（GitHub Pages）开屏即填满概览样本数字；真实引擎仍由用户点「只读扫描」，默认只看不动手。
- 方向 A/B/C 三份初稿 HTML 保留为历史探索记录，不再是上线前端。`report` 命令的自包含审计报告仍为暖纸账本风（独立产物，未改）。

### 验证
本机以双栈 mock 引擎在浏览器实测：9 视图切换、扫描/筛选/搜索、清理（ack 门）→Toast→结果、撤销、加固（链式 info 框）、清空撤销区（永久删除 ack 门）、重复快查/更新/软件搜索；桌面（1280×800：236px 侧栏＋3 列统计）与窄屏（504px：64px 图标轨）布局均经计算样式核验，全程零控制台报错。
